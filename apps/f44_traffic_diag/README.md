# Diagnostic panneaux F44

Cette application lit le catalogue SOME/IP local et affiche les interfaces et membres susceptibles de concerner les panneaux, limitations et feux. « Suivant » parcourt toutes les pages ; « Actualiser » relit le catalogue.

Elle ne s'abonne à aucun signal, ne montre aucun panneau sur le compteur et ne valide pas les données en direct. Un candidat dans le catalogue peut ne jamais publier de valeur sur cette voiture. Si le catalogue est inaccessible, son erreur est affichée.

Le résultat est à relever à l'arrêt. Ne pas publier le catalogue complet ni d'informations propres au véhicule. Après identification des candidats, une étape distincte sera nécessaire pour vérifier leurs valeurs et concevoir l'affichage.
